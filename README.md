# MA&A Prompt Library V1

This folder is a faithful baseline copy of the working Prompt Library before redesign or refactoring.

`index.html` is the authoritative application. It contains the page markup, prompt data, styling, and JavaScript functionality. The `fonts/` folder contains the local Sage font files referenced by the page.

## Preview locally

Open PowerShell in this folder and run:

```powershell
npx --yes serve . --listen 8000
```

Then open:

```text
http://localhost:8000
```

Press `Ctrl+C` in PowerShell to stop the preview server.
